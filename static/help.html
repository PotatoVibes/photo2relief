Parameter guide

What every slider does, and when to reach for it

← Back to the app

How the pipeline works

Your photo goes through three stages:

  1. Depth estimation — a neural depth model guesses how far every pixel is from the camera. This is the only slow step, and it runs once per photo per model; the result is cached. No slider below ever re-runs it.
  2. Heightmap shaping — every parameter on the Shaping and Size tabs re-shapes that cached depth into a 0–1 heightmap. This is instant, so tweak freely.
  3. Meshing — the heightmap becomes a watertight solid: your relief on top, vertical walls, flat back. Export-tab settings only affect this final step.

In the previews, brighter = higher = closer to the camera (grayscale mode shows this directly; the default hillshade view lights the surface like a raking lamp so you can judge the carve).

Because the two families distribute depth so differently, clip and threshold values do not transfer between models. On da2-* the whole background may live below 0.1 (use small thresholds like 0.02–0.08); on da3mono the same background can span 0.2–0.5.

Size tab

Width (mm)

10–1000 mm · default 150

Physical X size of the image content. Height is derived from the photo's aspect ratio, and a border frame adds to both dimensions on top of this (the finished-part size shows under the sliders). Everything in the app is millimeters, end to end — the exported STL matches these numbers exactly.

Relief height (mm)

0.5–100 mm · default 8

The Z range of the carved surface: the difference in height between the closest point in the photo and the farthest. Bigger values read more dramatically but need deeper cuts and steeper walls (think about your cutter's reach). For wall-hung wood reliefs around 150–250 mm wide, 6–15 mm is a good range.

Base thickness (mm)

0.5–50 mm · default 3

A solid flat slab underneath the relief. It's what keeps the part rigid and gives Fusion stock to hold onto. Total part thickness = base + relief height.

Border frame (mm)

0–50 mm · default 0 (off)

Adds a flat margin around the image at full stock height (base + relief). It's a machinable reference and clamping surface at the exact top-of-stock plane — useful for workholding, for facing checks, and for a clean physical frame. The frame is exactly this many millimeters wide and adds to the finished part's width and height (a 150 mm image with a 10 mm frame exports 170 mm wide).

Shaping tab — depth

Invert depth

off by default

Flips near and far: the subject becomes the deepest point instead of the highest. Use it to carve an intaglio (sunken relief) or a mold/stamp where the positive comes out of a casting.

Gamma

0.2–5.0 · default 1.0 (off)

A nonlinear remap of the heightmap. Above 1: background heights get compressed toward zero while contrast among the near/high parts widens — the subject pops, the room fades. Below 1: lifts the background and flattens subject contrast. This is usually the single most effective "make the subject stand out" knob.

Depth floor / depth ceiling

0–1 each · defaults 0 / 1 (off)

Clips the depth range before everything else, then re-stretches what survives to fill 0–1. Raising the floor merges everything farther than that value into the flat background — the standard way to kill busy room clutter behind a subject. Lowering the ceiling clamps blown-out foreground spikes (a hand or nose much closer than the rest) so they stop eating your whole relief range.

Flatten background + threshold

off by default · threshold 0–1, useful values are model-dependent

Hard-zeros every pixel below the threshold, giving a perfectly flat field around the subject — ideal when you want the subject floating on a clean plane rather than a fading room. Unlike the depth floor (which re-stretches), flatten leaves everything above the threshold untouched.

The right threshold depends on the photo and the model (see the tip above): on da2-* try 0.02–0.08; on da3mono try 0.2–0.5. Watch the grayscale preview: the flattened region goes pure black.

Shaping tab — surface

Smoothing (σ px)

0–10 · default 1.5

Gaussian blur on the heightmap. A little (1–2) removes depth-model noise and stair-stepping that would show as tooling chatter; a lot (4+) melts fine features into soft billows. If a ball-nose finishing pass is doing the final surface anyway, moderate smoothing costs you little.

Edge-preserving (bilateral)

off by default · uses the same σ slider

Swaps the Gaussian for a bilateral filter: flat areas still smooth out, but sharp height steps (the subject's silhouette against the background) stay crisp instead of blurring into a ramp. Slightly slower; worth trying when heavy smoothing starts eating the outline.

Detail blend (luminance)

0–1 · default 0.15

Depth models capture shape but smooth over fine texture — fur, hair, fabric weave. This adds a high-pass of the photo's brightness back onto the heightmap (the lithophane trick): at 1.0 it contributes about 15% of the relief range. Great for pet fur and hair; turn it down if photo lighting (shadows, glare) starts printing as false relief.

Edge taper (mm)

0–50 mm · default 0 (off)

Ramps the relief down to the base over the last N millimeters at the outer edge of the image content, so the picture doesn't end in an abrupt cliff at the panel border. Combine with a border frame for a "picture dissolving into its mat" look — or leave both off if the composition already fades naturally.

Export tab

Resolution (grid long side)

512 / 1024 / 2048 · default 1024

How many mesh vertices along the long side of the model. 1024 ≈ 2M triangles ≈ 100 MB STL — more than enough for a 3-axis finishing pass at typical sizes (at 200 mm wide, 1024 grid = one vertex every 0.2 mm, finer than a ball-nose stepover). Use 2048 only for very large panels; 512 for quick test cuts.

Decimation ratio

0–0.95 · default 0 (off)

After meshing, removes that fraction of triangles by collapsing edges where the surface is nearly flat (0.5 = roughly half the triangles). Shape change is negligible at moderate values; the point is file size and viewer snappiness, not machining quality — Fusion and its CAM handle 2M-triangle meshes fine, so leave this at 0 unless the files annoy you. The mesh is re-checked watertight after decimation.

Format

binary STL (default) or OBJ

STL is what Fusion's Insert → Insert Mesh expects; OBJ if some other tool in your chain prefers it. STL files carry no units — when Fusion asks on import, pick millimeters. The exported filename embeds the physical size (e.g. …_150x199.2mm.stl) so you can sanity-check the bounding box after import.

A suggested order of operations

  1. Pick the depth model first (geometric da3mono vs artistic da2) — every threshold below depends on it.
  2. Isolate the subject: raise the depth floor and/or enable flatten-background until the room is gone.
  3. Balance the range: gamma up to make the subject pop; ceiling down if one near feature dominates.
  4. Dress the surface: a little smoothing, bilateral if the silhouette suffers, detail blend for fur/hair.
  5. Physical size last: width, relief height, base, taper/frame — watch the derived size readout.
  6. Export at 1024 and check the summary line's dimensions before importing into Fusion (in mm!).

Example images are rendered from your own uploaded photo via the exact same pipeline the previews use — grayscale for level-type parameters (brighter = higher), hillshade for surface-texture ones.
